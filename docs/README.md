# 페어 매칭 프로그램 - [BE] 조상준

# 1. 기능 명세서
- 아래 기능 명세서는 사용자 서비스 흐름에 맞춰 작성되었습니다.

## 0. 부트스트랩
- [ ] 과정, 레벨별 미션에 대해 저장한다. 
- [ ] 과정에 해당하는 크루 정보를 저장한다.
- [ ] 기능 선택 목록(메인페이지)를 출력한다.

## 1. 프로그램 실행 최초 - 메인페이지
- [ ] 사용자에게 기능 선택을 입력 받는다.
  - 1,2,3,Q 중 하나를 입력할 수 있다.
- [ ] 각 기능이 모두 수행된 경우, 최초 페이지로 돌아온다.

## 2. 페어 매칭 기능을 선택한 경우
- [ ] 페어를 매칭할 "과정, 레벨, 미션"을 입력받는다.
- [ ] 기존에 해당 미션에 대한 매칭 결과가 있다면, 재매칭 희망여부를 입력받는다.
  - 네/아니오 중 하나를 입력할 수 있다.
- [ ] 각 과정, 레벨, 미션에 맞는 크루들을 매칭한다.
  - [ ] 전체 크루가 홀수인 경우, 한 페어는 3명으로 구성한다.
  - [ ] 같은 레벨의 다른 미션에 이미 동일 페어가 지정되었다면, 재 매칭한다.
- [ ] 매칭 결과를 출력하고, 메인페이지로 돌아간다.

## 3. 페어 조회 기능을 선택한 경우
- [ ] 조회할 "과정, 레벨, 미션"을 입력받는다.
- [ ] 아직 매칭되지 않았다면, 아직 매칭되지 않았따는
- [ ] 매칭 결과를 출력하고 최초 메인페이지로 돌아간다.

## 4. 페어 초기화 기능을 선택한 경우
- [ ] 전체 배정 결과를 초기화 한다.

## 5. 종료 기능을 선택한 경우
- [ ] 프로그램을 종료한다.
